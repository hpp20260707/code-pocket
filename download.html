Download & install

Code Pocket Bridge is a native macOS app that securely connects iPhone to the coding agent on your Mac.

这是一个通用安装包（Universal App），同时包含 Apple Silicon（arm64）和 Intel（x86_64）原生版本。只需下载一次，macOS 会自动选择适合当前 Mac 的版本，无需手动判断芯片类型，也不需要 Rosetta。

This is a Universal App containing native Apple silicon (arm64) and Intel (x86_64) versions. Download one package and macOS automatically selects the correct version for your Mac, with no manual choice or Rosetta required.

Provider compatibility

安装前，请确认 Mac 已安装并登录 Codex CLI 0.149.0 或更高版本。其他编码智能体 Provider 暂不支持。

安装流程

Installation

  1. 下载 Code-Pocket-Bridge.dmg。
  2. Download Code-Pocket-Bridge.dmg.
  3. 打开 DMG，将 Code Pocket Bridge 拖入“应用程序”。
  4. Open the DMG and drag Code Pocket Bridge to Applications.
  5. 首次打开时确认开发者与 Apple 公证信息。
  6. On first launch, verify the identified developer and Apple notarization prompt.
  7. 在 Bridge 中显示配对二维码，再使用 iPhone 扫描。
  8. Show the pairing QR code in Bridge, then scan it with iPhone.

发布安全

Release integrity

正式 Bridge 使用 Developer ID 签名、Hardened Runtime 与 Apple Notarization。安装包不会要求关闭 Gatekeeper，也不会要求 root 权限。

Official Bridge builds use Developer ID signing, Hardened Runtime, and Apple Notarization. Installation never requires disabling Gatekeeper or granting root access.
