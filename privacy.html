隐私政策

Privacy policy

本政策适用于 Code Pocket iPhone App、Code Pocket Bridge macOS App、配套公网 Relay 与本支持网站。

This policy applies to the Code Pocket iPhone app, Code Pocket Bridge for macOS, the encrypted internet relay, and this support site.

概览

Overview

Code Pocket 不要求创建产品账号，不包含广告 SDK，不使用第三方分析 SDK，也不出售个人数据。项目文件和 Provider 凭据保留在你的 Mac 上。iPhone 与已配对 Mac 之间的业务数据采用端到端加密。

Code Pocket does not require a product account, include advertising SDKs, use third-party analytics SDKs, or sell personal data. Project files and provider credentials remain on your Mac. Business data between the iPhone and paired Mac is end-to-end encrypted.

我们处理的数据

Data we process

  • 设备配对信息：设备生成的随机标识、设备名称、密钥材料和撤销状态保存在相应设备本地，用于识别已配对设备和恢复安全连接。
  • Device pairing information: Random identifiers, device names, key material, and revocation state are stored locally on the relevant devices to identify paired devices and recover secure sessions.
  • 安全与权益验证：Code Pocket 使用 Apple 的 App Attest、DeviceCheck 和 StoreKit 服务验证 App 合法性、管理免费额度及订阅权益。Relay 仅保存必要的匿名安全与配额信息，不关联账号，不用于广告或追踪；购买和账单由 Apple 处理。
  • Security and entitlement verification: Code Pocket uses Apple's App Attest, DeviceCheck, and StoreKit services to verify app legitimacy and manage free quotas and subscription entitlements. The relay stores only the anonymous security and quota information necessary for these purposes. It is not linked to an account or used for advertising or tracking. Apple handles purchases and billing.
  • 会话和项目内容：会话消息、计划、命令、文件变更、图片、用户选择的文件和相关项目元数据在 iPhone 与 Mac 之间端到端加密传输。公网 Relay 只转发有界密文，不解析业务内容，也不保存离线业务帧。
  • Conversation and project content: Messages, plans, commands, file changes, images, user-selected files, and related project metadata are end-to-end encrypted between iPhone and Mac. The internet relay forwards bounded ciphertext only; it does not parse business content or retain offline business frames.
  • 相机与照片：相机用于扫描配对二维码，并可在用户明确操作时拍摄要发送的图片。系统照片选择器只读取用户主动选择的图片。Code Pocket 不扫描完整照片图库。
  • Camera and photos: The camera scans pairing QR codes and, after an explicit action, captures images to send. The system photo picker reads only images the user selects. Code Pocket does not scan the full photo library.
  • 本地诊断：App 和 Bridge 可能在设备本地生成运行诊断。我们只有在你主动选择并发送时才会收到支持材料。提交前请删除项目内容、路径、凭据和个人信息。
  • Local diagnostics: The app and Bridge may generate operational diagnostics locally. We receive support material only when you explicitly choose to send it. Remove project content, paths, credentials, and personal information before sharing.

Provider 与第三方服务

Provider and third-party services

当你通过 Code Pocket 向编码智能体发送内容时，Code Pocket Bridge 会将明确提交的消息和附件交给你 Mac 上已登录的 Provider（当前首个 Provider 为 Codex CLI）。Provider 对数据的处理受你与该 Provider 之间的账号、产品条款和隐私政策约束。Code Pocket 不接收你的 Provider 登录凭据。

When you send content to a coding agent through Code Pocket, Code Pocket Bridge passes the explicitly submitted message and attachments to the provider signed in on your Mac (the first supported provider is Codex CLI). Provider processing is governed by the account, product terms, and privacy policy between you and that provider. Code Pocket does not receive your provider login credentials.

App 分发、App Attest 和设备平台能力由 Apple 提供；本支持站、Issues 与安装包下载由 GitHub 提供；公网 Relay 运行在中国大陆的云基础设施上。相关服务提供商可能依据各自政策处理网络请求所必需的信息。

Apple provides app distribution, App Attest, and platform capabilities. GitHub hosts this support site, Issues, and release downloads. The internet relay runs on cloud infrastructure in Mainland China. These providers may process information necessary to handle network requests under their own policies.

存储、保留与删除

Storage, retention, and deletion

配对凭据、缓存和会话状态按产品功能保存在 iPhone 或 Mac 本地。你可以在 App 中解除配对，并通过卸载 App 清除相应设备上的本地 App 数据。Mac 项目和 Provider 数据由你在 Mac 与 Provider 中管理。

Pairing credentials, caches, and conversation state are stored locally on iPhone or Mac as required by product functionality. You can unpair devices in the app and remove local app data by uninstalling the relevant app. You manage Mac project and provider data on the Mac and with the provider.

Relay 保存 App Attest 验证材料与配额状态，用于持续验证合法 App、防止重放和控制滥用，并在实现这些目的所需的期间保留。业务密文只在实时转发和有界连接队列中短暂存在，不作为离线消息保存。你可以通过支持邮箱提出与 Relay 验证数据相关的查询或删除请求；为避免泄露，不要在公开 Issue 中提交隐私请求或敏感信息。

The relay retains App Attest verification material and quota state to validate legitimate apps, prevent replay, and control abuse for as long as necessary for those purposes. Business ciphertext exists only briefly during real-time forwarding and bounded connection queues and is not stored as offline messages. You may request information about or deletion of relay verification data by email. Do not submit privacy requests or sensitive information in a public issue.

数据共享与追踪

Sharing and tracking

我们不会出售个人数据，不使用数据进行跨 App 或网站追踪，也不会将数据提供给广告网络或数据经纪商。除提供你明确请求的产品功能、保障安全、遵守法律或响应有效法律程序所必需的情况外，我们不会主动披露数据。

We do not sell personal data, track people across apps or websites, or provide data to advertising networks or data brokers. We do not disclose data except as necessary to provide explicitly requested functionality, protect security, comply with law, or respond to valid legal process.

权限与选择

Permissions and choices

你可以在 iOS 系统设置中管理相机、本地网络和照片相关权限。拒绝或撤回权限会使依赖该权限的扫码、局域网连接、拍照或选图功能不可用，但不会授权 Code Pocket 获取更多数据。

You can manage Camera, Local Network, and photo-related permissions in iOS Settings. Denying or revoking a permission disables dependent QR scanning, local connection, capture, or photo-selection features and never grants Code Pocket broader data access.

儿童隐私

Children’s privacy

Code Pocket 是面向开发工作的工具，并非为儿童设计。我们不会有意收集儿童的个人数据。如果你认为儿童向我们提供了个人数据，请通过邮箱联系我们。

Code Pocket is a development tool and is not designed for children. We do not knowingly collect children’s personal data. If you believe a child provided personal data, contact us by email.

Policy updates and contact

We may update this policy when product functionality, data handling, or legal requirements change and will identify the latest date on this page. Send privacy questions or data requests to codepocket@163.com.
