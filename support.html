Start here when installation, pairing, connection, or conversation display does not work as expected.

快速排查

Quick checks

  • 确认 iPhone 与 Mac App 都是最新且协议兼容的版本。
  • Confirm that both the iPhone and Mac apps are current and protocol-compatible.
  • 确认 Code Pocket Bridge 正在运行，Mac 上的 Codex CLI 已安装并登录。
  • Confirm that Code Pocket Bridge is running and Codex CLI is installed and signed in on the Mac.
  • 同一 Wi‑Fi 下优先检查本地网络权限；跨网络时检查公网连接状态。
  • On the same Wi‑Fi, check Local Network permission first; away from home, check the internet connection state.
  • 二维码过期或设备已解除配对时，请在 Bridge 中刷新二维码后重新扫描。
  • If the QR code expired or pairing was revoked, refresh the code in Bridge and scan again.

提交问题

Report an issue

Bug 与功能建议可以通过公开 GitHub Issue 提交。请勿在 Issue 中粘贴凭据、完整日志、项目源码、绝对路径、会话正文或其他敏感信息。

Use a public GitHub Issue for bugs and feature requests. Never include credentials, full logs, project source, absolute paths, conversation content, or other sensitive information.

创建 IssueOpen an issuecodepocket@163.com

提交前请准备

What to include

  • Code Pocket 与 Code Pocket Bridge 的版本号。
  • Code Pocket and Code Pocket Bridge version numbers.
  • iOS、macOS 与 Codex CLI 版本。
  • iOS, macOS, and Codex CLI versions.
  • 实际结果、预期结果和可重复的最短步骤。
  • Actual result, expected result, and the shortest reproducible steps.
  • 经过脱敏的截图；发送前检查通知、用户名、路径和项目内容。
  • Redacted screenshots; check notifications, usernames, paths, and project content before attaching.
